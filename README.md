### 🧭 关于我

我关注心理咨询中的人机交互，尤其是情感咨询 Agent 怎么跟人对话。一个人说「算了，反正说了也没用」，这时候该追问一句，还是先回应对方的感受？我对这些对话里的小选择感兴趣，也想知道它们会不会影响一个人愿不愿意继续说下去。
