### 🧭 About me

I'm learning to build AI agents that can handle multi-step tasks, and I study how language models process counseling dialogue. Two questions guide my work. How can we tell if an agent retrieved the right information and used its tools correctly? And when a counseling response reflects what someone said, can we find related signals inside the model?

I'm currently exploring **agent tool use, retrieval, and evaluation**. In my model research, I use sparse autoencoders (SAEs) to study model activations and find candidate features associated with reflective listening.
